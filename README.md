# Elite Ball Brawl

A 3D arena brawler in the style of The Strongest Battlegrounds: combos, dashes, ultimates and ragdolls against bots, or against friends with a room code.

Play at https://silverninja71.github.io/Elite-Ball-Brawl/ (add `#mute` to the address to start with sound off).

It is one self-contained `index.html`. To run it locally next to the other games, see the hub repo [`Empire`](https://github.com/SilverNinja71/Empire).
